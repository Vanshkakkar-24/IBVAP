Face Detection Model Architecture

This system uses the high-speed YuNet ONNX face detector by default, and includes a full deep learning training pipeline (app/training/train.py) to train a custom face detection network from scratch or fine-tune with PyTorch and export to ONNX.

Primary Model (YuNet)

Location: models/face_detection_yunet.onnx
Framework: OpenCV FaceDetectorYN
Inference: ONNX Runtime / OpenCV DNN
Speed: ~40-60 FPS on standard CPU

Custom Trained Model (TinyFaceNet)

Location: models/custom_face_detector.onnx
Framework: PyTorch ➔ ONNX Export
Outputs: Face Logits, BBox Regressor, 5 Landmarks
Trained via: python -m app.training.train

How To Train Your Custom Face Model

You can train a custom face detection neural network right from your terminal. Follow these steps:

# 1. (Optional) Capture training samples directly from your webcam:
python -m app.training.dataset --capture-webcam --samples 50

# 2. Run the training loop (synthetic or captured samples):
python -m app.training.train --epochs 10 --batch-size 16 --lr 0.001

# 3. The script automatically evaluates mAP and exports the ONNX model to:
# models/custom_face_detector.onnx

# 4. To run live webcam detection with the custom model:
python -m app.detect_webcam --camera-index 0
